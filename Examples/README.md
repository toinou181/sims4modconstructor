# Example Projects

This directory contains example Sims 4 mod projects that demonstrate the capabilities of the Sims 4 Mod Constructor.

## ExampleProject.s4mp

A complete example mod project that includes:

### Interactions
- **Friendly Hug**: A friendly interaction that makes sims happy and energized
- **Tell Funny Joke**: A playful interaction that puts sims in a playful mood

### Buffs
- **Feeling Happy**: A positive mood buff (Happy, +2, 240 minutes)
- **Playful Mood**: A playful mood buff (Playful, +1, 180 minutes)
- **Energized**: An energized mood buff (Energized, +1, 120 minutes)

### Traits
- **Super Sociable**: A personality trait for social sims (conflicts with Loner, Antisocial)
- **Creative Genius**: A hobby trait for creative sims

## How to Use

1. Open the Sims 4 Mod Constructor application
2. Go to File → Open Project
3. Select `ExampleProject.s4mp`
4. View, edit, or export the mod as needed

## Exporting the Example

To export this example mod:

1. Load the project
2. Go to File → Export Mod
3. Choose an output directory
4. The mod will be exported in both XML and Python (.ts4script) formats

The exported structure will include:
- XML files for game data
- Python scripts for mod logic
- A README with installation instructions
